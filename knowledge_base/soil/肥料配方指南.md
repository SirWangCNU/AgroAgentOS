# 科学施肥与肥料配方指南

## 第一章 肥料基础知识

### 1.1 肥料分类

**按来源分类：**
- **化学肥料**：人工合成
- **有机肥料**：动植物残体
- **微生物肥料**：有益微生物

**按养分分类：**
- **氮肥**：提供氮素
- **磷肥**：提供磷素
- **钾肥**：提供钾素
- **复合肥**：含两种以上养分
- **微量元素肥料**：含微量元素

### 1.2 肥料三要素

**氮（N）：**
- 作用：促进茎叶生长
- 缺乏症状：叶片发黄，生长缓慢
- 过量症状：徒长，易倒伏

**磷（P₂O₅）：**
- 作用：促进根系发育和开花结果
- 缺乏症状：叶片紫红色，根系发育差
- 过量症状：影响微量元素吸收

**钾（K₂O）：**
- 作用：增强抗逆性，提高品质
- 缺乏症状：叶缘焦枯，易倒伏
- 过量症状：影响镁、钙吸收

### 1.3 肥料利用率

**各肥料利用率：**
- 氮肥：30-50%
- 磷肥：10-25%
- 钾肥：40-60%

**提高利用率措施：**
1. 深施覆土
2. 分次施用
3. 与有机肥配合
4. 使用缓释肥

## 第二章 测土配方施肥

### 2.1 测土配方原理

**定义：**
根据土壤测试结果和作物需肥规律，提出合理的施肥方案。

**原则：**
1. 因土因作物施肥
2. 有机无机配合
3. 缺素补素
4. 经济合理

### 2.2 测土配方步骤

**第一步：采集土样**
- 采样时间：作物收获后或播种前
- 采样深度：0-20cm
- 采样方法：多点混合

**第二步：土壤测试**
- 测试项目：pH、有机质、N、P、K
- 测试方法：常规分析法

**第三步：制定配方**
- 计算作物需肥量
- 计算土壤供肥量
- 确定肥料用量

**第四步：施肥指导**
- 确定施肥时期
- 确定施肥方法
- 配方肥生产

### 2.3 配方计算方法

**目标产量法：**
```
施肥量 = (目标产量需肥量 - 土壤供肥量) / (肥料含量 × 利用率)
```

**养分平衡法：**
```
施肥量 = (作物需肥量 - 土壤供肥量) / 肥料养分含量
```

**示例：**
- 目标产量：500kg/亩（水稻）
- 需氮量：500 × 2.5/100 = 12.5kg/亩
- 土壤供氮：6kg/亩
- 尿素含氮：46%
- 利用率：40%
- 施氮量：(12.5-6)/0.46/0.4 = 35.3kg/亩

## 第三章 常见作物施肥方案

### 3.1 水稻施肥方案

**基肥：**
- 有机肥：1000-1500kg/亩
- 复合肥（15-15-15）：30-40kg/亩

**分蘖肥：**
- 尿素：5-8kg/亩
- 时间：插秧后7-10天

**穗肥：**
- 复合肥（15-15-15）：10-15kg/亩
- 时间：幼穗分化期

**粒肥：**
- 尿素：2-3kg/亩
- 时间：抽穗后

### 3.2 小麦施肥方案

**基肥：**
- 有机肥：2000-3000kg/亩
- 复合肥（15-15-15）：40-50kg/亩

**返青肥：**
- 尿素：5-10kg/亩
- 时间：返青期

**拔节肥：**
- 尿素：10-15kg/亩
- 时间：拔节期

**叶面肥：**
- 磷酸二氢钾：0.2-0.3%溶液
- 时间：灌浆期

### 3.3 玉米施肥方案

**基肥：**
- 有机肥：1500-2000kg/亩
- 复合肥（15-15-15）：30-40kg/亩

**苗肥：**
- 尿素：5-8kg/亩
- 时间：3-5叶期

**穗肥：**
- 尿素：15-20kg/亩
- 时间：大喇叭口期

**粒肥：**
- 磷酸二氢钾：叶面喷施
- 时间：灌浆期

### 3.4 蔬菜施肥方案

**叶菜类：**
- 基肥：有机肥2000kg/亩 + 复合肥30kg/亩
- 追肥：尿素10-15kg/亩，分2-3次

**茄果类：**
- 基肥：有机肥3000kg/亩 + 复合肥50kg/亩
- 追肥：高钾肥20-30kg/亩，分3-4次

**瓜类：**
- 基肥：有机肥2500kg/亩 + 复合肥40kg/亩
- 追肥：高钾肥15-20kg/亩，分2-3次

## 第四章 有机肥使用

### 4.1 农家肥

**猪粪：**
- 养分含量：N 0.6%，P₂O₅ 0.4%，K₂O 0.4%
- 特点：肥效快，适合追肥
- 用量：1000-1500kg/亩

**牛粪：**
- 养分含量：N 0.3%，P₂O₅ 0.25%，K₂O 0.1%
- 特点：肥效慢，适合基肥
- 用量：1500-2000kg/亩

**鸡粪：**
- 养分含量：N 1.6%，P₂O₅ 1.5%，K₂O 0.8%
- 特点：养分高，需腐熟
- 用量：500-800kg/亩

### 4.2 商品有机肥

**选择标准：**
1. 有机质含量≥45%
2. N+P₂O₅+K₂O≥5%
3. 有效活菌数≥2000万/g
4. 水分≤30%

**使用方法：**
- 基肥：200-400kg/亩
- 沟施或穴施
- 与土壤混匀

### 4.3 生物有机肥

**功能：**
1. 提供养分
2. 改良土壤
3. 促进生长
4. 增强抗性

**使用方法：**
- 基肥：100-200kg/亩
- 避免与杀菌剂混用
- 保存在阴凉处

## 第五章 叶面施肥技术

### 5.1 叶面肥种类

**大量元素叶面肥：**
- 尿素溶液：0.5-1%
- 磷酸二氢钾：0.2-0.3%

**微量元素叶面肥：**
- 硼肥：硼砂0.1-0.2%
- 锌肥：硫酸锌0.1-0.2%
- 铁肥：硫酸亚铁0.2-0.5%

**氨基酸叶面肥：**
- 含氨基酸≥10%
- 促进光合作用
- 增强抗逆性

### 5.2 叶面施肥技术

**喷施时间：**
- 早晨或傍晚
- 避免中午高温
- 无风天气

**喷施方法：**
- 均匀喷施叶片正反面
- 雾滴细小
- 以叶片湿润不滴水为宜

**注意事项：**
1. 浓度不宜过高
2. 不能与碱性农药混用
3. 喷后4小时遇雨重喷
4. 交替使用不同叶面肥

## 第六章 新型肥料

### 6.1 缓控释肥料

**特点：**
- 养分释放缓慢
- 提高利用率
- 减少施肥次数
- 环境友好

**种类：**
- 包膜肥料
- 缓溶性肥料
- 化学抑制型肥料

**使用方法：**
- 一次性基施
- 用量减少20-30%
- 适合机械化施肥

### 6.2 水溶性肥料

**特点：**
- 水溶性好
- 适合滴灌
- 见效快
- 利用率高

**种类：**
- 大量元素水溶肥
- 中微量元素水溶肥
- 含腐植酸水溶肥
- 含氨基酸水溶肥

**使用方法：**
- 滴灌：5-10kg/亩
- 冲施：10-15kg/亩
- 叶面喷施：0.1-0.3%

### 6.3 微生物肥料

**种类：**
- 根瘤菌剂
- 固氮菌剂
- 解磷菌剂
- 解钾菌剂
- 复合微生物肥

**功能：**
1. 固氮
2. 解磷
3. 解钾
4. 促生
5. 防病

**使用方法：**
- 拌种：50-100g/亩
- 灌根：100-200g/亩
- 基施：100-200kg/亩

**注意事项：**
1. 避免与杀菌剂混用
2. 保存在阴凉处
3. 不能暴晒
4. 有效期注意
