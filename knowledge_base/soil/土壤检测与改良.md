# 土壤检测与改良技术

## 第一章 土壤基础知识

### 1.1 土壤组成

**土壤三相组成：**
- **固相**：矿物质（45%）+ 有机质（5%）
- **液相**：土壤水分（25%）
- **气相**：土壤空气（25%）

**土壤质地分类：**
- **砂土**：砂粒含量>70%，透气性好，保水性差
- **壤土**：砂粒、粉粒、粘粒适中，最适宜种植
- **粘土**：粘粒含量>30%，保水性好，透气性差

### 1.2 土壤pH值

**pH值分级：**
- 强酸性：<4.5
- 酸性：4.5-5.5
- 微酸性：5.5-6.5
- 中性：6.5-7.5
- 微碱性：7.5-8.5
- 碱性：8.5-9.5
- 强碱性：>9.5

**适宜作物生长的pH范围：**
- 大多数作物：6.0-7.5
- 蓝莓、杜鹃：4.5-5.5
- 苜蓿、甜菜：7.0-8.0

## 第二章 土壤检测方法

### 2.1 土样采集

**采样原则：**
1. 代表性：能代表整个地块
2. 随机性：多点混合采样
3. 适时性：作物收获后或播种前

**采样方法：**
1. 划分采样单元
2. 每单元采5-10个点
3. 采样深度：0-20cm（耕作层）
4. 混合四分法取1kg样品

**采样注意事项：**
- 避开田边、沟渠、堆肥处
- 用竹铲或土钻采样
- 装入干净布袋或塑料袋
- 标签注明地点、时间、深度

### 2.2 常规检测项目

**必测项目：**
- pH值
- 有机质
- 全氮
- 速效磷
- 速效钾

**选测项目：**
- 碱解氮
- 中微量元素（Ca、Mg、S、Fe、Mn、Zn、Cu、B）
- 重金属（Cd、Pb、Cr、As、Hg）
- 盐分

### 2.3 检测方法

**pH值测定：**
- 方法：电位法（水土比2.5:1）
- 仪器：酸度计
- 标准：NY/T 1121.2

**有机质测定：**
- 方法：重铬酸钾氧化法
- 仪器：消解炉、滴定装置
- 标准：NY/T 1121.6

**全氮测定：**
- 方法：凯氏定氮法
- 仪器：凯氏定氮仪
- 标准：NY/T 53

**速效磷测定：**
- 方法：Olsen法（中性、石灰性土壤）
- 方法：Bray-1法（酸性土壤）
- 标准：NY/T 1121.7

**速效钾测定：**
- 方法：乙酸铵浸提-火焰光度法
- 仪器：火焰光度计
- 标准：NY/T 889

## 第三章 土壤改良技术

### 3.1 酸性土壤改良

**改良材料：**
- **石灰**：CaO或Ca(OH)₂
- **白云石粉**：CaMg(CO₃)₂
- **草木灰**：含K₂O 5-10%

**施用方法：**
1. 根据pH值确定用量
2. 均匀撒施
3. 深翻入土
4. 与有机肥配合

**石灰用量参考：**

| 土壤pH | 目标pH | 石灰用量（kg/亩） |
|--------|--------|-------------------|
| 4.5 | 6.5 | 150-200 |
| 5.0 | 6.5 | 100-150 |
| 5.5 | 6.5 | 50-100 |
| 6.0 | 6.5 | 30-50 |

### 3.2 碱性土壤改良

**改良材料：**
- **石膏**：CaSO₄·2H₂O
- **硫磺**：S
- **硫酸亚铁**：FeSO₄
- **酸性肥料**：过磷酸钙、硫酸铵

**施用方法：**
1. 石膏撒施后翻耕
2. 硫磺与土壤混合
3. 配合灌溉洗盐
4. 种植耐盐作物

**石膏用量参考：**

| 土壤pH | 目标pH | 石膏用量（kg/亩） |
|--------|--------|-------------------|
| 8.5 | 7.5 | 200-300 |
| 9.0 | 7.5 | 300-400 |
| 9.5 | 7.5 | 400-500 |

### 3.3 盐碱地改良

**改良措施：**
1. **水利改良**：灌水洗盐、挖沟排水
2. **农业改良**：深耕、增施有机肥
3. **化学改良**：施用改良剂
4. **生物改良**：种植耐盐植物

**耐盐作物：**
- 棉花：耐盐极限0.4%
- 向日葵：耐盐极限0.4%
- 甜菜：耐盐极限0.5%
- 大麦：耐盐极限0.5%

### 3.4 粘性土壤改良

**改良方法：**
1. 增施有机肥
2. 掺入砂土
3. 深耕晒垡
4. 种植绿肥

**有机肥用量：**
- 堆肥：2000-3000kg/亩
- 秸秆还田：500-800kg/亩
- 绿肥：1500-2000kg/亩

### 3.5 砂性土壤改良

**改良方法：**
1. 增施有机肥
2. 掺入粘土
3. 使用保水剂
4. 覆盖地膜

**保水剂使用：**
- 用量：3-5kg/亩
- 方法：与土壤混合
- 效果：提高保水性30-50%

## 第四章 土壤培肥技术

### 4.1 有机肥施用

**有机肥种类：**
- 农家肥：猪粪、牛粪、鸡粪
- 商品有机肥：工厂化生产
- 生物有机肥：含有益微生物

**施用原则：**
1. 腐熟后施用
2. 与化肥配合
3. 深施覆土
4. 适量施用

**施用量：**
- 农家肥：1000-2000kg/亩
- 商品有机肥：200-400kg/亩
- 生物有机肥：100-200kg/亩

### 4.2 秸秆还田

**还田方式：**
- 直接还田：粉碎翻压
- 堆沤还田：堆腐后施用
- 过腹还田：喂畜后施用

**注意事项：**
1. 粉碎彻底
2. 配合施氮肥
3. 补充水分
4. 防止病虫害传播

### 4.3 绿肥种植

**常见绿肥作物：**
- 豆科：紫云英、苜蓿、苕子
- 禾本科：黑麦草、燕麦
- 十字花科：油菜、萝卜

**种植技术：**
1. 选择适宜品种
2. 适时播种
3. 合理施肥
4. 适时翻压

**翻压时期：**
- 盛花期翻压
- 翻压深度15-20cm
- 翻压后灌水

## 第五章 土壤污染防治

### 5.1 土壤污染类型

**重金属污染：**
- 来源：工业废水、农药、化肥
- 危害：影响作物品质，危害人体健康
- 标准：GB 15618

**有机污染：**
- 来源：农药、塑料薄膜
- 危害：影响土壤生物，残留超标
- 标准：GB 15618

### 5.2 污染防治措施

**源头控制：**
1. 控制工业排放
2. 合理使用农药化肥
3. 推广可降解地膜

**过程阻断：**
1. 施用钝化剂
2. 调节pH值
3. 增施有机肥

**末端治理：**
1. 植物修复
2. 微生物修复
3. 化学淋洗
4. 客土覆盖

### 5.3 安全利用

**农艺措施：**
1. 选择低积累品种
2. 调节pH值
3. 水分管理
4. 合理施肥

**替代种植：**
- 种植非食用作物
- 种植花卉苗木
- 种植能源作物
