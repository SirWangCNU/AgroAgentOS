# 农业气象灾害防御指南

## 第一章 气象灾害概述

### 1.1 气象灾害分类

**按成因分类：**
- **温度灾害**：霜冻、冻害、高温热害
- **水分灾害**：干旱、洪涝、渍害
- **光照灾害**：寡照、日灼
- **风雹灾害**：大风、冰雹
- **复合灾害**：干热风、连阴雨

### 1.2 气象灾害特点

1. **区域性**：不同地区灾害类型不同
2. **季节性**：与季节变化密切相关
3. **突发性**：部分灾害难以预测
4. **群发性**：多种灾害常同时发生
5. **连锁性**：可引发病虫害等次生灾害

## 第二章 温度灾害

### 2.1 霜冻

**定义：**
地面温度降到0℃以下，造成作物伤害。

**类型：**
- **辐射霜冻**：晴夜辐射冷却形成
- **平流霜冻**：冷空气入侵形成
- **混合霜冻**：两者共同作用

**发生时期：**
- 春季：晚霜冻（3-5月）
- 秋季：早霜冻（9-11月）

**防御措施：**

**农业措施：**
1. 选择抗冻品种
2. 适时播种，避开霜冻
3. 覆盖地膜、草帘
4. 熏烟增温

**物理措施：**
1. 灌水保温
2. 喷施防冻剂
3. 搭建防霜棚
4. 使用防霜风机

**化学措施：**
1. 喷施磷酸二氢钾
2. 喷施芸苔素内酯
3. 使用抗冻剂

### 2.2 冻害

**定义：**
作物在越冬期间因低温造成的伤害。

**受害症状：**
- 叶片：水浸状，后干枯
- 茎秆：开裂，变色
- 根系：腐烂，变黑
- 生长点：死亡

**易发作物：**
- 冬小麦
- 冬油菜
- 果树
- 蔬菜

**防御措施：**
1. 选择抗寒品种
2. 适时播种，培育壮苗
3. 浇好越冬水
4. 覆盖保温
5. 镇压保墒

### 2.3 高温热害

**定义：**
气温超过作物生长适宜温度，造成伤害。

**受害症状：**
- 叶片：萎蔫、灼伤
- 花器：花粉活力下降
- 果实：日灼、裂果
- 根系：吸收能力下降

**易发作物：**
- 水稻：高温逼熟
- 玉米：花期高温
- 蔬菜：落花落果
- 果树：日灼

**防御措施：**
1. 选择耐热品种
2. 调整播种期
3. 灌水降温
4. 遮阳覆盖
5. 喷施抗蒸腾剂

## 第三章 水分灾害

### 3.1 干旱

**定义：**
长期无雨或少雨，土壤水分不足。

**类型：**
- **春旱**：3-5月
- **夏旱**：6-8月
- **秋旱**：9-11月
- **冬旱**：12-2月

**受害症状：**
- 叶片：萎蔫、卷曲
- 生长：缓慢、停滞
- 产量：严重减产
- 品质：下降

**防御措施：**

**工程措施：**
1. 兴修水利
2. 发展灌溉
3. 修建蓄水池

**农业措施：**
1. 选择抗旱品种
2. 调整播种期
3. 覆盖保墒
4. 节水灌溉

**化学措施：**
1. 使用保水剂
2. 喷施抗蒸腾剂
3. 使用抗旱种衣剂

### 3.2 洪涝

**定义：**
降雨过多，造成积水成涝。

**类型：**
- **洪灾**：河水泛滥
- **涝灾**：地面积水
- **渍害**：土壤过湿

**受害症状：**
- 根系：缺氧，腐烂
- 叶片：发黄，脱落
- 茎秆：软弱，倒伏
- 产量：严重减产

**防御措施：**

**工程措施：**
1. 修建排水系统
2. 疏浚河道
3. 修建防洪堤

**农业措施：**
1. 选择耐涝品种
2. 高畦种植
3. 及时排水
4. 扶苗洗苗

**补救措施：**
1. 及时排水
2. 扶苗洗苗
3. 补种改种
4. 追肥促长

### 3.3 渍害

**定义：**
土壤长期过湿，影响作物生长。

**发生条件：**
- 地下水位高
- 排水不良
- 连续阴雨

**受害症状：**
- 根系：发黑，腐烂
- 叶片：发黄，生长缓慢
- 产量：下降

**防御措施：**
1. 开沟排水
2. 深翻晒垈
3. 增施有机肥
4. 选择耐渍品种

## 第四章 风雹灾害

### 4.1 大风

**定义：**
风力达到6级以上的风。

**危害：**
- 机械损伤：折断、倒伏
- 加速蒸发：加重干旱
- 传播病害：扩大发病范围
- 影响授粉：降低结实率

**易发时期：**
- 春季：冷空气活动频繁
- 夏季：雷雨大风
- 秋季：台风影响

**防御措施：**
1. 营造防护林
2. 搭建防风设施
3. 选择抗风品种
4. 适时培土

### 4.2 冰雹

**定义：**
固态降水，由冰粒组成。

**危害：**
- 机械损伤：叶片、茎秆、果实
- 植株倒伏
- 引发病害

**易发地区：**
- 山区
- 沿河地区
- 冷暖空气交汇处

**防御措施：**

**预防措施：**
1. 关注天气预报
2. 搭建防雹网
3. 覆盖保护

**补救措施：**
1. 及时清理残体
2. 喷施杀菌剂
3. 追肥促长
4. 补种改种

## 第五章 复合灾害

### 5.1 干热风

**定义：**
高温、低湿、有一定风力的灾害性天气。

**发生时期：**
- 小麦灌浆期（5-6月）

**危害：**
- 造成小麦逼熟
- 千粒重下降
- 产量损失10-30%

**防御措施：**
1. 选择抗旱品种
2. 浇好灌浆水
3. 喷施磷酸二氢钾
4. 营造防护林

### 5.2 连阴雨

**定义：**
连续5天以上的阴雨天气。

**危害：**
- 影响光合作用
- 加重病害发生
- 影响授粉结实
- 造成烂根烂果

**易发时期：**
- 春季：3-5月
- 秋季：9-11月

**防御措施：**
1. 选择耐阴品种
2. 加强排水
3. 防治病害
4. 人工授粉

## 第六章 灾后补救措施

### 6.1 粮食作物

**水稻灾后管理：**
1. 及时排水
2. 扶苗洗苗
3. 追施速效肥
4. 防治病虫害

**小麦灾后管理：**
1. 排水降湿
2. 追施恢复肥
3. 防治病害
4. 适时收获

### 6.2 经济作物

**蔬菜灾后管理：**
1. 及时排水
2. 清理残体
3. 补种改种
4. 防治病害

**果树灾后管理：**
1. 清理断枝
2. 伤口保护
3. 追肥恢复
4. 防治病害

### 6.3 通用措施

1. **及时排水**：降低田间湿度
2. **清理残体**：减少病害发生
3. **追肥促长**：恢复作物生长
4. **防治病害**：防止次生灾害
5. **补种改种**：减少损失
6. **保险理赔**：减轻经济负担
