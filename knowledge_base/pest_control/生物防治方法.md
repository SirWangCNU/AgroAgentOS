# 生物防治方法

## 第一章 生物防治概述

### 1.1 生物防治定义

生物防治是利用有益生物或其他生物来抑制或消灭有害生物的防治方法。

### 1.2 生物防治优点

1. **环境友好**：不污染环境
2. **安全性高**：对人畜安全
3. **可持续性**：不产生抗药性
4. **生态平衡**：保护天敌

### 1.3 生物防治类型

- **以虫治虫**：利用天敌昆虫
- **以菌治虫**：利用病原微生物
- **以菌治病**：利用拮抗微生物
- **生物农药**：植物源、微生物源农药

## 第二章 天敌昆虫利用

### 2.1 捕食性天敌

**瓢虫：**
- 寄主：蚜虫、介壳虫、红蜘蛛
- 释放量：每亩释放200-500头
- 释放时期：害虫发生初期
- 保护措施：减少化学农药使用

**草蛉：**
- 寄主：蚜虫、红蜘蛛、粉虱
- 释放量：每亩释放300-500头
- 释放时期：害虫发生初期

**捕食螨：**
- 寄主：红蜘蛛、锈螨
- 释放量：每亩释放5000-10000头
- 释放时期：害螨发生初期
- 注意事项：避免使用杀螨剂

**食蚜蝇：**
- 寄主：蚜虫
- 保护措施：种植蜜源植物

### 2.2 寄生性天敌

**赤眼蜂：**
- 寄主：玉米螟、棉铃虫、松毛虫
- 释放量：每亩释放1-2万头
- 释放时期：害虫产卵初期
- 释放方法：将蜂卡挂在作物上

**丽蚜小蜂：**
- 寄主：白粉虱
- 释放量：每亩释放3000-5000头
- 释放时期：粉虱发生初期

**蚜茧蜂：**
- 寄主：蚜虫
- 释放量：每亩释放500-1000头
- 保护措施：种植蜜源植物

### 2.3 天敌保护措施

**栖息地营造：**
1. 种植蜜源植物
2. 保留田边杂草
3. 设置天敌越冬场所

**农业措施：**
1. 合理轮作
2. 适当放宽防治指标
3. 选择对天敌安全的农药

## 第三章 微生物防治

### 3.1 细菌制剂

**苏云金杆菌（Bt）：**
- 作用机理：产生伴孢晶体毒素
- 防治对象：鳞翅目害虫
- 使用方法：喷雾，每亩100-200g
- 注意事项：对家蚕高毒

**枯草芽孢杆菌：**
- 作用机理：竞争营养和空间
- 防治对象：土传病害
- 使用方法：灌根或拌种
- 优点：促进植物生长

**蜡质芽孢杆菌：**
- 作用机理：产生抗菌物质
- 防治对象：枯萎病、黄萎病
- 使用方法：灌根

### 3.2 真菌制剂

**白僵菌：**
- 作用机理：孢子接触害虫体壁萌发
- 防治对象：玉米螟、松毛虫、蛴螬
- 使用方法：喷粉或撒施
- 注意事项：高湿环境效果好

**绿僵菌：**
- 作用机理：类似白僵菌
- 防治对象：蝗虫、蛴螬
- 使用方法：喷雾或撒施

**木霉菌：**
- 作用机理：寄生病原菌
- 防治对象：土传病害
- 使用方法：土壤处理
- 优点：促进植物生长

### 3.3 病毒制剂

**核型多角体病毒（NPV）：**
- 作用机理：感染害虫细胞
- 防治对象：棉铃虫、斜纹夜蛾
- 使用方法：喷雾
- 特点：高度专一性

**颗粒体病毒（GV）：**
- 作用机理：类似NPV
- 防治对象：菜青虫、小菜蛾
- 使用方法：喷雾

### 3.4 抗生素类

**井冈霉素：**
- 作用机理：抑制病原菌
- 防治对象：纹枯病
- 使用方法：喷雾或灌根

**春雷霉素：**
- 作用机理：抑制蛋白质合成
- 防治对象：稻瘟病、细菌性病害
- 使用方法：喷雾

**多抗霉素：**
- 作用机理：抑制病原菌
- 防治对象：灰霉病、霜霉病
- 使用方法：喷雾

## 第四章 植物源农药

### 4.1 常见植物源农药

**苦参碱：**
- 来源：苦参
- 作用：杀虫、杀菌
- 防治对象：蚜虫、红蜘蛛、白粉病
- 特点：低毒、易降解

**印楝素：**
- 来源：印楝树
- 作用：拒食、抑制生长
- 防治对象：多种害虫
- 特点：对天敌安全

**鱼藤酮：**
- 来源：鱼藤
- 作用：触杀、胃毒
- 防治对象：蚜虫、菜青虫
- 注意事项：对鱼高毒

**除虫菊素：**
- 来源：除虫菊
- 作用：触杀
- 防治对象：蚊蝇、蚜虫
- 特点：见光分解

### 4.2 植物源农药使用

**优点：**
1. 环境友好
2. 不易产生抗药性
3. 对天敌安全
4. 易降解

**局限性：**
1. 速效性差
2. 持效期短
3. 成本较高

## 第五章 生物防治应用技术

### 5.1 以虫治虫技术

**天敌释放技术：**
1. 确定释放时期
2. 计算释放量
3. 选择释放方法
4. 监测防治效果

**效果评估：**
- 虫口减退率
- 天敌种群变化
- 作物受害程度

### 5.2 以菌治虫技术

**微生物农药使用：**
1. 选择适宜菌种
2. 掌握使用条件
3. 配合农业措施
4. 注意环境因素

**影响因素：**
- 温度：20-30℃效果好
- 湿度：高湿效果好
- 光照：避免强光
- pH值：中性偏酸

### 5.3 综合应用

**生防与其他措施配合：**
1. 与农业防治配合
2. 与物理防治配合
3. 与化学防治协调

**注意事项：**
1. 提前释放天敌
2. 选择对天敌安全的农药
3. 避免高峰期施药
4. 保护天敌栖息地
