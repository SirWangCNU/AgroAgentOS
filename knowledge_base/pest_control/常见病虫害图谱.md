# 常见病虫害图谱与识别

## 第一章 病害识别基础

### 1.1 病害分类

**按病原分类：**
- **真菌性病害**：占病害总数70-80%
- **细菌性病害**：占病害总数10-15%
- **病毒性病害**：占病害总数5-10%
- **线虫病害**：占病害总数3-5%

**按侵染方式分类：**
- **侵染性病害**：由病原微生物引起
- **非侵染性病害**：由环境因素引起

### 1.2 病害识别要点

**观察部位：**
1. 叶片：斑点、枯萎、畸形
2. 茎秆：腐烂、变色、溃疡
3. 根部：腐烂、变色、肿瘤
4. 果实：腐烂、变色、畸形

**病征观察：**
- 霉状物：真菌病害特征
- 脓状物：细菌病害特征
- 粉状物：白粉病、锈病
- 颗粒状：菌核病

## 第二章 常见病害图谱

### 2.1 叶部病害

**霜霉病：**
- 症状：叶片正面出现黄色斑块，背面出现灰白色霉层
- 发生条件：低温高湿，昼夜温差大
- 典型作物：黄瓜、葡萄、十字花科蔬菜
- 防治药剂：烯酰吗啉、霜脲氰、甲霜灵

**白粉病：**
- 症状：叶片表面出现白色粉状物，后期出现小黑点
- 发生条件：高温干燥，通风不良
- 典型作物：小麦、黄瓜、草莓
- 防治药剂：三唑酮、腈菌醚、醚菌酯

**灰霉病：**
- 症状：病部出现灰色霉层，软腐
- 发生条件：低温高湿
- 典型作物：番茄、草莓、花卉
- 防治药剂：嘧霉胺、腐霉利、异菌脲

**叶斑病：**
- 症状：叶片出现圆形或不规则斑点
- 发生条件：高温高湿
- 典型作物：水稻、玉米、蔬菜
- 防治药剂：多菌灵、代森锰锌、百菌清

### 2.2 茎部病害

**枯萎病：**
- 症状：植株萎蔫，维管束变褐
- 发生条件：高温高湿，土壤带菌
- 典型作物：西瓜、番茄、棉花
- 防治方法：轮作、嫁接、药剂灌根

**茎腐病：**
- 症状：茎基部变褐腐烂，易折断
- 发生条件：高温多雨
- 典型作物：玉米、大豆
- 防治药剂：甲基硫菌灵、多菌灵

**菌核病：**
- 症状：病部出现黑色菌核
- 发生条件：低温高湿
- 典型作物：油菜、大豆、蔬菜
- 防治药剂：菌核净、异菌脲

### 2.3 根部病害

**根腐病：**
- 症状：根部腐烂，地上部萎蔫
- 发生条件：土壤积水，透气性差
- 典型作物：各种蔬菜、果树
- 防治方法：改善排水，药剂灌根

**猝倒病：**
- 症状：幼苗茎基部水渍状，倒伏
- 发生条件：低温高湿
- 典型作物：蔬菜苗期
- 防治药剂：恶霉灵、甲霜灵

**立枯病：**
- 症状：幼苗茎基部缢缩，直立枯死
- 发生条件：高温高湿
- 典型作物：蔬菜苗期
- 防治药剂：恶霉灵、甲基立枯磷

## 第三章 常见虫害图谱

### 3.1 刺吸式害虫

**蚜虫：**
- 形态：体小，绿色或黑色
- 危害：吸食汁液，分泌蜜露，传播病毒
- 发生时期：春季和秋季
- 防治药剂：吡虫啉、啶虫脒、噻虫嗪

**白粉虱：**
- 形态：体小，白色，有翅
- 危害：吸食汁液，分泌蜜露
- 发生时期：夏季高温期
- 防治药剂：噻虫嗪、吡丙醚

**蓟马：**
- 形态：体微小，黄褐色
- 危害：锉吸叶片和花
- 发生时期：高温干燥期
- 防治药剂：乙基多杀菌素、多杀霉素

**红蜘蛛：**
- 形态：体微小，红色
- 危害：吸食叶片汁液
- 发生条件：高温干燥
- 防治药剂：阿维菌素、螺螨酯

### 3.2 咀嚼式害虫

**菜青虫：**
- 形态：绿色，体软
- 危害：啃食叶片，留下孔洞
- 发生时期：春秋两季
- 防治药剂：甲维盐、氯虫苯甲酰胺

**棉铃虫：**
- 形态：体色多变，有条纹
- 危害：蛀食果实和蕾铃
- 发生时期：夏季
- 防治药剂：氯虫苯甲酰胺、茚虫威

**小菜蛾：**
- 形态：体小，灰褐色
- 危害：啃食叶片，留下透明表皮
- 发生时期：春秋两季
- 防治药剂：甲维盐、虫螨腈

**夜蛾类：**
- 形态：体中型，灰褐色
- 危害：夜间活动，啃食叶片
- 发生时期：夏季
- 防治药剂：甲维盐、虫螨腈

### 3.3 地下害虫

**蛴螬：**
- 形态：体肥大，弯曲呈C形
- 危害：啃食根部
- 发生时期：春季和秋季
- 防治药剂：辛硫磷、毒死蜱

**金针虫：**
- 形态：体细长，金黄色
- 危害：钻蛀根部和茎基部
- 发生时期：春季
- 防治药剂：辛硫磷、毒死蜱

**地老虎：**
- 形态：体灰褐色，有条纹
- 危害：咬断幼苗茎基部
- 发生时期：春季
- 防治药剂：辛硫磷、毒死蜱

## 第四章 病虫害综合防治策略

### 4.1 防治原则

**"预防为主，综合防治"方针：**
1. 农业防治：轮作、抗病品种、合理施肥
2. 物理防治：色板诱杀、灯光诱杀、防虫网
3. 生物防治：天敌、微生物农药
4. 化学防治：科学用药，安全间隔期

### 4.2 防治时期

**关键防治时期：**
- 播种期：种子处理
- 苗期：病虫害初发期
- 生长盛期：病虫害高发期
- 采收前：安全间隔期

### 4.3 科学用药

**用药原则：**
1. 对症下药：准确识别病虫害
2. 适时用药：抓住防治关键期
3. 交替用药：防止产生抗药性
4. 安全用药：注意安全间隔期

**安全间隔期：**
- 叶菜类：7-10天
- 茄果类：5-7天
- 瓜类：3-5天
