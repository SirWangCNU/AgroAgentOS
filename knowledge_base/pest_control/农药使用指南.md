# 农药安全使用指南

## 第一章 农药基础知识

### 1.1 农药分类

**按用途分类：**
- **杀虫剂**：防治害虫
- **杀菌剂**：防治病害
- **除草剂**：防除杂草
- **植物生长调节剂**：调节植物生长

**按来源分类：**
- **化学农药**：人工合成
- **生物农药**：微生物或植物提取
- **矿物农药**：矿物源

### 1.2 农药剂型

**常见剂型：**
- **乳油（EC）**：有效成分溶于有机溶剂
- **可湿性粉剂（WP）**：粉状，可兑水喷雾
- **悬浮剂（SC）**：固体颗粒悬浮于水中
- **水分散粒剂（WG）**：颗粒状，入水崩解
- **颗粒剂（G）**：直接撒施

### 1.3 农药标识

**标签内容：**
1. 农药名称（通用名、商品名）
2. 有效成分含量
3. 剂型
4. 毒性标识
5. 使用范围和方法
6. 安全间隔期
7. 生产日期和保质期

## 第二章 杀虫剂使用

### 2.1 有机磷类

**特点：**
- 广谱、高效
- 有内吸性
- 毒性较高
- 易产生抗药性

**常见品种：**
- 毒死蜱：防治地下害虫、蚜虫
- 辛硫磷：防治地下害虫
- 敌敌畏：防治多种害虫

**使用注意：**
- 不能与碱性农药混用
- 注意安全防护
- 严格掌握用量

### 2.2 氨基甲酸酯类

**特点：**
- 选择性强
- 毒性中等
- 见效快

**常见品种：**
- 克百威：防治地下害虫
- 丁硫克百威：防治蚜虫
- 抗蚜威：专杀蚜虫

### 2.3 拟除虫菊酯类

**特点：**
- 广谱、高效
- 毒性低
- 击倒速度快

**常见品种：**
- 高效氯氰菊酯：防治多种害虫
- 溴氰菊酯：防治鳞翅目害虫
- 甲氰菊酯：防治红蜘蛛

### 2.4 新烟碱类

**特点：**
- 内吸性强
- 持效期长
- 对蜜蜂高毒

**常见品种：**
- 吡虫啉：防治蚜虫、飞虱
- 啶虫脒：防治蚜虫
- 噻虫嗪：防治刺吸式害虫

**使用注意：**
- 花期禁止使用
- 避免污染水源

### 2.5 生物源杀虫剂

**阿维菌素：**
- 来源：链霉菌发酵
- 特点：广谱、低毒、环保
- 防治对象：红蜘蛛、蚜虫、小菜蛾

**苏云金杆菌（Bt）：**
- 来源：细菌
- 特点：专一性强，对人畜安全
- 防治对象：鳞翅目害虫

**核型多角体病毒：**
- 来源：昆虫病毒
- 特点：高度专一
- 防治对象：棉铃虫、斜纹夜蛾

## 第三章 杀菌剂使用

### 3.1 保护性杀菌剂

**代森锰锌：**
- 特点：广谱保护性杀菌剂
- 防治：霜霉病、炭疽病、早疫病
- 用法：发病前喷雾预防

**百菌清：**
- 特点：非内吸性保护剂
- 防治：霜霉病、白粉病、锈病
- 用法：发病前喷雾

**波尔多液：**
- 成分：硫酸铜+石灰
- 特点：保护性杀菌剂
- 防治：霜霉病、炭疽病
- 注意：对金属有腐蚀性

### 3.2 内吸性杀菌剂

**多菌灵：**
- 特点：广谱内吸性杀菌剂
- 防治：枯萎病、根腐病、叶斑病
- 用法：喷雾或灌根

**甲基硫菌灵：**
- 特点：内吸传导性好
- 防治：白粉病、炭疽病
- 用法：喷雾

**三唑类：**
- 三唑酮：防治锈病、白粉病
- 丙环唑：防治叶斑病
- 戊唑醇：防治纹枯病、赤霉病

### 3.3 专性杀菌剂

**霜脲氰：**
- 特点：专治霜霉病
- 防治：黄瓜霜霉病、葡萄霜霉病
- 用法：发病初期喷雾

**烯酰吗啉：**
- 特点：专治霜霉病
- 防治：霜霉病、疫病
- 用法：发病初期喷雾

**嘧霉胺：**
- 特点：专治灰霉病
- 防治：灰霉病
- 用法：发病初期喷雾

## 第四章 除草剂使用

### 4.1 除草剂分类

**按使用时期分类：**
- **播前处理剂**：播种前使用
- **播后苗前处理剂**：播种后出苗前使用
- **苗后处理剂**：杂草出苗后使用

**按作用方式分类：**
- **灭生性除草剂**：杀死所有植物
- **选择性除草剂**：只杀死特定杂草

### 4.2 常见除草剂

**草甘膦：**
- 类型：灭生性、内吸传导型
- 用途：果园、非耕地除草
- 注意：见绿即杀，避免漂移

**乙草胺：**
- 类型：选择性、芽前处理
- 用途：玉米、大豆田除草
- 注意：土壤处理，保持湿度

**莠去津：**
- 类型：选择性、内吸传导型
- 用途：玉米田除草
- 注意：残效期长，注意后茬

### 4.3 除草剂使用技术

**使用原则：**
1. 准确选择除草剂
2. 严格掌握用量
3. 注意使用时期
4. 均匀喷雾

**注意事项：**
- 避免高温施药
- 避免大风天施药
- 注意后茬作物
- 交替使用不同类型

## 第五章 农药安全使用

### 5.1 个人防护

**防护装备：**
- 防护服：长袖长裤
- 防护手套：橡胶手套
- 防护口罩：活性炭口罩
- 防护眼镜：护目镜

**防护措施：**
1. 施药前穿戴防护装备
2. 施药时避免饮食、吸烟
3. 施药后及时清洗
4. 出现中毒症状立即就医

### 5.2 安全间隔期

**安全间隔期定义：**
最后一次施药到作物采收的间隔天数。

**常见作物安全间隔期：**

| 作物 | 农药 | 安全间隔期 |
|------|------|------------|
| 叶菜 | 吡虫啉 | 7天 |
| 番茄 | 阿维菌素 | 5天 |
| 黄瓜 | 百菌清 | 3天 |
| 苹果 | 多菌灵 | 7天 |

### 5.3 农药储存

**储存要求：**
1. 原包装密封保存
2. 阴凉干燥处存放
3. 远离食品和饲料
4. 儿童接触不到的地方

**废弃处理：**
- 空包装集中回收
- 残液妥善处理
- 不随意丢弃

### 5.4 中毒急救

**中毒症状：**
- 有机磷中毒：瞳孔缩小、出汗、流涎
- 拟除虫菊酯中毒：皮肤瘙痒、头晕

**急救措施：**
1. 立即脱离现场
2. 脱去污染衣物
3. 用清水冲洗皮肤
4. 误服者立即催吐
5. 送医院救治
