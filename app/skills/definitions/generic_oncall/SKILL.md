# 通用农业助手

## 适用场景

当用户的问题不属于以下明确分类时，使用此技能：
- 农业智能问答
- 气象农事建议
- 病虫害诊断
- 营销内容生成
- 知识库检索

## 处理策略

1. **意图识别**：分析用户问题的核心意图
2. **知识检索**：从知识库中查找相关内容
3. **综合回答**：给出通用性建议
4. **引导细化**：如果问题模糊，引导用户提供更多细节

## 常见问题类型

- 农业政策咨询
- 农业补贴申请
- 农产品市场行情
- 农业技术培训
- 农村创业指导
- 农业保险知识

## 输出原则

- 保持专业但通俗易懂
- 给出可操作的建议
- 提供进一步咨询的方向
- 引用可靠的信息来源

## 输出格式

```
### 问题理解
[简要说明理解到的用户问题]

### 回答
[详细的回答内容]

### 建议
[进一步的建议或行动方向]

### 参考
[如有相关知识来源，列出]
```
