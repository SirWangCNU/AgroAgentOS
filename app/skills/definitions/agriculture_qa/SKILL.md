# 农业智能问答

## 适用场景

- 用户询问各类作物的种植技术
- 用户咨询施肥、灌溉、田间管理等问题
- 用户想了解养殖技术（家禽、家畜、水产等）
- 用户询问农事安排、农时节气相关问题

## 推荐回答步骤

1. **理解问题意图**：明确用户询问的是哪种作物/养殖对象，哪个环节的问题
2. **检索知识库**：查询相关农业知识，获取专业资料支持
3. **结合实际情况**：如有天气信息，结合当地气候条件给出建议
4. **给出具体建议**：提供可操作的步骤，避免空泛回答
5. **补充注意事项**：提醒可能的风险和预防措施

## 输出格式

```
### 问题分析
[简要分析用户问题的核心要点]

### 专业建议
[详细的农业技术建议，分步骤说明]

### 注意事项
[需要特别注意的风险或禁忌]

### 知识来源
[引用的知识库文档，如有]
```

## 示例

**用户问**：现在适合种玉米吗？

**回答要点**：
- 查询当地当前天气和气温
- 检索玉米播种的适宜温度和季节要求
- 给出是否适合播种的判断
- 如果不适合，说明原因和建议等待的条件
