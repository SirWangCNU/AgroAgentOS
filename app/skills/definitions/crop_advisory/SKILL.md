# 种植顾问

## 适用场景

- 用户询问作物施肥方案（N/P/K 配比）
- 用户需要灌溉建议（浇水量、时机）
- 用户咨询播种期推荐
- 用户需要种植日历或田间管理建议
- 用户描述作物生长阶段，询问下一步操作
- 用户询问土壤改良方案

## 诊断流程

1. **确认作物信息**
   - 作物种类和品种
   - 当前生长阶段（幼苗/营养生长/花期/结果期）
   - 所在地区（省/市）

2. **获取环境数据**
   - 调用天气工具获取近 3 天天气
   - 关注温度、降水、湿度、风速

3. **检索知识库**
   - 查询作物栽培技术手册
   - 获取施肥配方建议
   - 了解该作物的关键管理要点

4. **综合建议**
   - 灌溉：结合近 3 天降水量、气温、作物需水量给出「今天是否需要浇水」及用水量建议
   - 施肥：按作物生长阶段（幼苗/营养生长/花期/结果期）给出 N/P/K 配比建议
   - 播种期推荐：根据用户所在地理位置和目标作物，推算最佳播种窗口
   - 病虫害预防：结合天气提示高发病害及预防措施

## 常见作物生长阶段管理要点

### 蔬菜类（番茄/黄瓜/辣椒等）
- 幼苗期：控水蹲苗，轻施氮肥
- 营养生长：加大氮肥，保持土壤湿润
- 花期：控氮增磷钾，适当控水防落花
- 结果期：重施钾肥，均匀供水

### 粮食作物（水稻/小麦/玉米等）
- 分蘖/拔节期：重施氮肥
- 孕穗/抽穗期：补施穗肥
- 灌浆期：叶面喷施磷酸二氢钾

### 果树类
- 萌芽期：施萌芽肥（氮为主）
- 花期：喷硼促花
- 果实膨大期：重施钾肥
- 采后：施基肥恢复树势

## 输出格式

```
### 当前情况
[作物种类 + 生长阶段 + 环境条件摘要]

### 灌溉建议
[是否需要浇水、浇水量、时机]

### 施肥方案
[N/P/K 配比、用量、施肥方式]

### 田间管理
[当前阶段的关键管理要点]

### 病虫害预防
[结合天气的高发病害预警及预防措施]

### 知识来源
[引用的栽培资料]
```
