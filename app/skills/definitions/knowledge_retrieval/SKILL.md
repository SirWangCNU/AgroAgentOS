# 农业知识库检索

## 适用场景

- 用户需要查阅农业技术资料
- 用户想了解某种作物的种植规范
- 用户需要查询农药、肥料的使用标准
- 用户想获取农业政策、标准等信息

## 知识库内容分类

### 种植技术
- 粮食作物：水稻、小麦、玉米、大豆等
- 经济作物：棉花、油料、糖料等
- 蔬菜：叶菜、果菜、根茎类等
- 果树：苹果、柑橘、葡萄、桃等
- 茶叶、中药材等特种作物

### 病虫害防治
- 常见病虫害图谱
- 农药使用指南
- 绿色防控技术
- 生物防治方法

### 土壤肥料
- 土壤检测与改良
- 肥料配方与施用技术
- 有机肥制作与使用
- 水肥一体化技术

### 农业气象
- 农业气象灾害防御
- 天气与农事安排
- 气候适应性种植

### 农业机械
- 农机使用与维护
- 农机农艺融合
- 智慧农业装备

## 检索策略

1. **关键词检索**：提取用户问题中的核心关键词
2. **语义检索**：理解用户意图，检索语义相关的内容
3. **混合排序**：结合相关性和权威性排序结果
4. **上下文关联**：返回相关联的知识片段，保持信息完整性

## 输出格式

```
### 检索结果

#### 结果1：[文档标题]
**来源**：[文档名称]
**相关度**：[百分比]
**内容摘要**：
[检索到的核心内容片段]

#### 结果2：[文档标题]
...

### 综合建议
[基于检索结果给出的综合建议]
```

## 引用规范

- 每条建议都应注明知识来源
- 引用权威资料（农业部指南、科研论文等）
- 标注资料的时效性（发布日期）
- 区分"通用建议"和"地方性建议"
