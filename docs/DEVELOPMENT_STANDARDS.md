# AgroAgentOS 编码规范

> 本规范只约束代码的编写与修改。人类开发者和 AI 编码助手均必须遵守。

## 1. 基本原则

- 修改前必须阅读现有实现、相邻测试和相关类型，先理解再编码。
- 只修改完成当前需求所必需的代码，禁止顺手重构无关模块。
- 保持函数、类和组件职责单一；重复逻辑应提取到合适的公共层。
- 命名必须表达业务含义；注释说明原因、边界和取舍，不复述代码。
- 必须保护用户已有的未提交改动，不得覆盖、删除或混入无关文件。

## 2. Python 与 FastAPI

- `app/api/v1/` 只处理参数、鉴权、依赖注入和响应组装。
- 业务逻辑放在 `app/services/`，路由禁止直接访问数据库。
- 数据库、LLM、Redis、Milvus 和外部服务适配放在 `app/core/` 或明确的工具层。
- 请求和响应使用 `app/schemas/` 中的 Pydantic 模型；统一响应使用 `ApiResponse[T]`。
- 业务异常使用 `AppException` 体系，禁止捕获后静默忽略或伪造成功。
- 异步接口禁止直接执行阻塞 I/O；必须使用异步客户端或线程卸载。
- 公共函数必须有清晰类型标注，禁止用无约束 `dict` 代替已有 schema 或领域类型。

## 3. React 与 TypeScript

- API 和 SSE 调用集中在 `frontend-react/src/api/`，页面中不得重复实现认证逻辑。
- 服务端状态使用 React Query，跨页面客户端状态使用 Zustand，局部状态留在组件内。
- 共享类型放在 `frontend-react/src/types/`，并与后端接口保持一致。
- 禁止使用无理由的 `any`、双重断言或关闭类型检查来绕过错误。
- 页面和组件必须处理加载、空数据、错误和成功状态。
- 组件应保持职责清晰；复杂逻辑提取为 hook 或独立组件。

## 4. 微信小程序

- 网络、认证和存储统一复用 `agroagent-miniapp/miniprogram/services/` 与 `utils/`。
- 页面必须处理加载、错误、空数据、重复请求和登录失效。
- 禁止在页面中硬编码后端地址、Token、密钥或重复公共请求逻辑。
- 修改页面时同步检查对应的 JS、JSON、WXML 和 WXSS。

## 5. Agent、Skill 与工具

- 保持 `SkillRouter → Planner → Executor → Replanner` 的职责边界。
- 工具调用必须经过现有运行时，Planner 和 Router 不得直接执行工具。
- 新增 Skill 必须正确填写 frontmatter、`allowed_tools`、`risk_level` 和执行模式。
- 高风险写工具不得默认执行；LLM 输出必须校验后再使用。
- 必须处理工具失败、解析失败、重试上限和无法收敛的情况。

## 6. 数据、配置与安全

- ORM 或表结构变更必须新增 Alembic 迁移，并兼容 SQLite 与 MySQL。
- 结构化文本字段沿用 `_json` 命名和属性解析约定。
- 新增环境变量必须加入 `app/config.py` 的 `Settings` 和 `.env.example`。
- 禁止提交真实密钥、Token、密码、Cookie、私钥或本地 `.env`。
- 外部输入必须校验；日志不得包含敏感信息或完整敏感请求体。
- 新增依赖前先确认现有依赖不能满足需求，并更新正确的依赖清单。

## 7. 测试要求

- 修改业务逻辑时必须新增或更新相关测试，测试应验证真实行为和失败路径。
- Python 改动至少运行相关 `pytest`；核心跨模块改动运行全量 `pytest`。
- React/TypeScript 改动运行 `npm run lint` 和 `npm run build`。
- 数据库结构变更检查 Alembic 升级；小程序改动验证受影响页面流程。
- 禁止删除测试、弱化断言、隐藏失败或修改测试来迎合错误实现。
- 无法运行验证时必须说明原因，不得声称测试已经通过。

## 8. AI 编码流程

1. 编码前：读取本规范，检查 `git status`，定位现有实现和测试。
2. 编码中：保持最小改动，遵守分层、类型和错误处理规则。
3. 编码后：检查差异，运行相关验证，报告修改文件、验证结果和剩余风险。

## 9. 禁止事项

- 禁止路由直接访问数据库或堆放大段业务逻辑。
- 禁止吞掉异常、返回虚假成功或泄露内部堆栈。
- 禁止用 `any`、无约束字典或关闭检查逃避类型问题。
- 禁止修改数据库结构却不提供迁移。
- 禁止硬编码环境地址、密钥和机器路径。
- 禁止覆盖用户改动、扩大任务范围或进行无关重构。
- 禁止在未验证时声称代码已经完成或测试通过。
