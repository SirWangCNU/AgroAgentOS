# AgroAgentOS 文档

本目录只记录当前农业平台仍在使用的设计与开发资料。

| 文档 | 内容 |
|------|------|
| `architecture.md` | 当前后端、Agent、数据存储和前端结构 |
| `skill_development_guide.md` | 农业 Skill 的编写与验证方法 |
| `weather_calendar_agent_plan.md` | 天气与农事日历功能设计 |
| `PHASE_PLAN.md` | 阶段性开发计划，仅作项目演进参考 |
| `superpowers/plans/` | 具体改造任务的实施计划 |

农业知识库原始文档放在项目根目录 `knowledge_base/`，使用
`scripts/ingest_agriculture_kb.py` 导入。旧 OnCall SOP 和 Prometheus 告警语料已移除。
