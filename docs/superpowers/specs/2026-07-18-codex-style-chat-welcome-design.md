# Codex 风格对话欢迎页设计

## 目标

将当前空对话页重构为一个单焦点的农业 AI 工作入口。页面应接近 Codex 的工具型极简气质，同时保留 AgroAgentOS 的品牌识别和现有上传图片、联网搜索、MCP 工具、发送消息能力。

## 视觉方向

- 使用温和的灰白背景、深墨色标题和克制的农业绿作为唯一强调色。
- 页面中心只保留品牌标识、主标题和输入工作台，避免功能门户式卡片与装饰性数据面板。
- 不使用发光 Logo、渐变光斑、独立状态条、悬浮标签或纵向快捷建议。
- 阴影仅用于让输入工作台从背景中轻微抬起，边框和圆角保持精确、克制。

## 布局

1. 主内容在可用视口内略高于垂直中心，最大宽度约 768px。
2. 顶部显示 40px 左右的品牌图标，下方为单行标题“今天想解决什么农业问题？”。
3. 标题与输入区之间保留充足留白，不再显示说明段落和能力状态条。
4. 输入工作台高度约 128px，文本输入位于上半部，工具栏固定在底部。
5. 工具栏左侧为图片上传、联网搜索和 MCP 工具，右侧为发送或停止按钮。
6. 工具启用状态通过按钮自身的颜色和背景表达，不在输入框外重复显示文字标签。

## 交互

- 点击图片按钮沿用现有文件选择、格式校验、大小校验和预览逻辑。
- 联网与 MCP 按钮沿用现有开关状态；使用 tooltip 说明状态。
- `Enter` 发送，`Shift + Enter` 换行，发送中显示停止按钮。
- 输入框随内容增长，但在欢迎态保持稳定的最小高度，避免页面跳动。
- 图片预览作为输入工作台内部区域出现，不生成额外的外部卡片。

## 组件范围

- `WelcomeScreen.tsx`：仅负责品牌标识和标题。
- `ChatInput.tsx`：负责统一输入工作台、图片预览、工具切换和发送控制。
- `Chat.tsx`：负责空状态的居中布局与背景，不改变消息流和请求逻辑。

## 响应式与可访问性

- 桌面端最大宽度约 768px；移动端使用页面边距并保持按钮可点击区域不小于 40px。
- 标题在窄屏自然换行，输入区不横向溢出。
- 所有图标按钮提供可读的 `title` 或 `aria-label`，焦点态清晰可见。
- 保持足够的文字和边框对比度。

## 验证

- 对修改的组件运行 ESLint。
- 运行 `npm run build` 完成 TypeScript 与生产构建检查。
- 在桌面和移动视口检查垂直位置、输入框尺寸、工具状态、图片预览及无内容溢出。
